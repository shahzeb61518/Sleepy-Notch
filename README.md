# Sleepy Notch website

The public home page and privacy policy for the Sleepy Notch Android app, served by GitHub Pages.

- `index.html`: home page
- `privacy-policy.html`: privacy policy (the app and the Play listing link here)
- `assets/`: stylesheet, the CSS eyes script, icon and feature graphic

Plain HTML and CSS, no build step. Open `index.html` in a browser to preview.
